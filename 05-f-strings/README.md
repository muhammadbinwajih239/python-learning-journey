# Python f-Strings

This project contains beginner-friendly examples of useful Python f-string features.

## Topics Covered

1. Variables inside strings
2. Multiple variables in one sentence
3. Simple calculations
4. String method calls inside f-strings
5. Decimal precision
6. Comma separators for large numbers
7. Percentage formatting
8. Left, right, and center alignment
9. Leading zeros
10. Positive and negative signs
11. Binary, octal, and hexadecimal formatting
12. Debugging with the equals sign
13. The `!s`, `!r`, and `!a` conversion specifiers
14. Printing literal curly braces
15. Dynamic field width and precision
16. Date and time formatting

## How to Run

1. Make sure Python 3.8 or newer is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python f_strings.py
```

On some Windows systems, use:

```bash
py f_strings.py
```

The examples use only Python's standard library. No third-party packages are required.

## Purpose

The goal is to practice f-strings through simple variables and `print()` statements, and learn how to format text, numbers, and dates.
