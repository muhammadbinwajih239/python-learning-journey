# Academy Attendance Tracker

A beginner-level Python project to practise tuples, dictionaries, and sets through a simple academy attendance example.

## Project Features

- Store student names and course information.
- Display all student records.
- Search for a student using their ID.
- Store Saturday and Sunday attendance.
- Compare attendance for both days.

## Python Concepts Practised

### Tuples
- Store student names and course information.
- Tuple unpacking.

### Dictionaries
- Store student records using key-value pairs.
- Use get() to search for student records.
- Use items() to display records.

### Sets
- Store unique student IDs.
- Union
- Intersection
- Difference
- Symmetric Difference
